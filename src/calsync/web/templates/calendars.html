Purpose guide

Pick the simplest purpose that matches how each calendar should affect planning. Hover the question-mark hint beside a chooser if you want the same explanation right next to the field.

  • Check availability

    Check this calendar when looking for busy time and scheduling conflicts.

  • Conflict checking only

    Use this when the calendar blocks time, but should not become your preferred personal schedule source.

  • Receive new bookings

    Only available on writable calendars. CalSync can create new appointments here once write-back is enabled.

  • Personal reference

    Keep the calendar visible for context without letting it drive booking decisions.

  • Hidden

    Keep the connection, but remove the calendar from active planning views.
