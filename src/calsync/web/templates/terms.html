CalSync

Terms of Use

CalSync is a household scheduling tool for a shared family calendar. Use it only with calendars and channels you are authorized to manage.

Intended use

Create, edit, read, and cancel appointments for the connected family scheduling workspace.

Operator responsibility

The person running this deployment is responsible for Apple calendar credentials, Cloudflare configuration, and any enabled channels.

No guarantees

This service is provided as-is for household scheduling. Always check important appointments if a calendar channel is being reconfigured.

Channel rules

  • Shared brain, separate channels

    The web console, ChatGPT edge, and Alexa skill all act on the same appointment store and the same Apple-backed scheduling logic. This shared brain keeps every channel aligned to one schedule.

  • Voice access can be disabled

    Alexa remains unavailable until the operator enables the channel and approves a real skill ID for this deployment.

  • Respect calendar ownership

    Only use CalSync to manage calendars you are permitted to edit. The service should not be used to impersonate or override other people’s schedules.
